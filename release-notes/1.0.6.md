# Galactifun Legacy 1.0.6

Galactifun Legacy `1.0.6` cleans up its Slimefun Guide layout so the addon remains contained under the existing top-level **Galactifun** folder.

## Guide organization

- Kept **Planets & Universe** inside the Galactifun parent folder.
- Kept **Assembly Table Recipes** inside the Galactifun parent folder.
- Removed the duplicate top-level guide entries for those custom pages.
- Existing items, recipes, world/planet systems, and registrations are unchanged.

## Compatibility

- Slimefun Legacy
- Paper/Purpur 26.2
- Paper 1.21.11 API compile baseline
- Java 21 bytecode, built with Java 25

Install the raw release JAR in `plugins/`:

`SF_Glactifun1.0.6.jar`
